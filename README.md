# EDGE-FPGA-Kit-Board-Files
This repository consist of EDGE FPGA kit Board Files

Read Board File Installation PDF for the procedure to add EDGE boards to vivado design suite

For more information visit allaboutfpga.com 

## EDGE Artix 7 XC7A50T and XC7A100T variants

The EDGE Artix 7 board is also built with the XC7A50T and XC7A100T FPGAs (same PCB). Use these board files for those variants:

| Folder | Board name in Vivado | FPGA part |
|---|---|---|
| `edgeA7_50t/1.0` | EDGE Artix 7 (XC7A50T) | xc7a50tftg256-1 |
| `edgeA7_100t/1.0` | EDGE Artix 7 (XC7A100T) | xc7a100tftg256-1 |

The XC7A35T board keeps using the `edgeA7` board file.
